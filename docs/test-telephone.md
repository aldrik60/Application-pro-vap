# Test sur téléphone avant le lancement

À faire le jeudi 29 octobre, sur **un iPhone (Safari)** et **un Android (Chrome)**, avec une adresse e-mail de test par téléphone (par exemple `provapcreil+iphone@gmail.com` et `provapcreil+android@gmail.com`, qui arrivent dans la même boîte Gmail).

Pour chaque étape : notez **OK**, ou décrivez ce qui ne va pas avec une capture d'écran. Envoyez-moi la liste à la fin, je corrige le vendredi.

| # | Étape | Ce qui doit se passer | iPhone | Android |
|---|---|---|---|---|
| 1 | Scanner le QR code imprimé (affiche boutique) | L'app s'ouvre sur l'écran de connexion Pro'Vap | | |
| 2 | « Créer un compte » : prénom, e-mail, mot de passe | Le bouton reste grisé tant que les **deux cases** ne sont pas cochées | | |
| 3 | Cocher les deux cases, valider | « Compte créé. Bienvenue. » puis l'onboarding, sans e-mail à confirmer | | |
| 4 | Onboarding : écran 1 (mascotte), écran 2 avec **date d'arrêt « Autre date » il y a 100 jours**, écran 3 boutique | On arrive sur l'accueil, compteur à 100 jours | | |
| 5 | Accueil : lire le message du jour | Un message s'affiche (série après J90) | | |
| 6 | Accueil : la mascotte et la carte « Prochain jalon » | Mascotte visible, texte lisible, rien ne déborde | | |
| 7 | Installer l'app sur l'écran d'accueil (iPhone : bouton Partager puis « Sur l'écran d'accueil » ; Android : menu puis « Installer ») | L'icône bouddha apparaît, l'app s'ouvre sans barre d'adresse (sur iPhone, il faut se reconnecter une fois) | | |
| 8 | Profil : activer les notifications | La fenêtre « Restons en contact », puis la demande du téléphone, puis « Notifications Pro'Vap activées » | | |
| 9 | Depuis l'Admin (votre compte), envoyer une notification test à ce compte | Elle arrive sur le téléphone, même app fermée | | |
| 10 | Bouton SOS au centre | Respiration guidée plein écran, pause et retour fonctionnent | | |
| 11 | Accueil : « Une cigarette ? Ce n'est pas grave. » | La fenêtre bienveillante s'ouvre, « Respirer 3 minutes » mène au SOS | | |
| 12 | Check-in humeur sur l'accueil, puis Journal | L'humeur du jour apparaît dans le journal | | |
| 13 | Onglet Vape : ajouter un point d'étape à 12 mg/ml | Le plan affiche 12 → 9 → 6 → 3 → 0, environ 6 semaines par palier | | |
| 14 | Ressources (carte « Guides & conseils » de l'accueil) | 10 guides, la FAQ, **pas** de section Vidéos ; ouvrir 2 guides : texte propre, pas de « \n » | | |
| 15 | Profil : test de Fagerström | Résultat et conseil de taux, mention « recommandé par la HAS » | | |
| 16 | Profil : demande de rendez-vous conseiller | Confirmation à l'écran, e-mail reçu sur rdv@pro-vap.fr | | |
| 17 | Couper le wifi et les données, rouvrir l'app | L'app s'ouvre, la mascotte s'affiche (les données se rechargent au retour du réseau) | | |
| 18 | Mentions légales (bas de l'écran de connexion) | Siège à Compiègne, contact rgpd@pro-vap.com, mise à jour du 24 octobre 2026 | | |
| 19 | Mode sombre du téléphone activé | Textes lisibles partout, mascotte sans taches blanches | | |
| 20 | Le vendredi 30 à 9 h, avant de supprimer les comptes de test | Chaque téléphone reçoit « Jour 101 · Votre message du jour » (le compte a démarré il y a 100 jours le jeudi) | | |
| 21 | Profil : supprimer le compte de test | Le compte disparaît, retour à l'écran de connexion | | |

**Avec votre compte admin, en plus :**
- Admin → Vidéos : ajouter une vidéo YouTube de test (même une vidéo publique quelconque). Elle doit apparaître dans Ressources sur le téléphone, puis la supprimer.
- Admin → Articles : ouvrir un guide, corriger un mot, enregistrer : la correction apparaît dans l'app.
