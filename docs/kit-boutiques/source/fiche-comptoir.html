Installer My Pro'Vap

Le client tient son téléphone. Vous lui montrez où toucher, vous ne tapez pas son mot de passe à sa place.

iPhone · Safari

  1. Scannez le QR code avec l'appareil photo et ouvrez le lien dans Safari. S'il s'ouvre ailleurs (Chrome, Instagram…) : copiez le lien et collez-le dans Safari.
  2. Bouton Partager, puis « Sur l'écran d'accueil », puis « Ajouter ». Le carré avec une flèche vers le haut. Sur les iPhone récents, il est dans le menu « ••• ».
  3. Ouvrez l'app depuis sa nouvelle icône et reconnectez-vous une fois. Même e-mail, même mot de passe. C'est normal sur iPhone, ça n'arrive qu'une fois.

Android · Chrome

  1. Scannez le QR code et ouvrez le lien dans Chrome.
  2. Touchez le bandeau « Installer » s'il apparaît. Sinon : menu ⋮ en haut à droite, puis « Installer l'application » ou « Ajouter à l'écran d'accueil ».
  3. Confirmez, puis ouvrez l'app depuis sa nouvelle icône. Le client reste connecté.

Pour finir, sur les deux téléphones
  • Onglet Profil : « Activer les notifications », puis accepter la demande du téléphone. Sur iPhone, depuis l'icône installée, pas depuis Safari.
  • Montrez le bouton SOS au centre, en bas de l'écran : c'est celui dont le client se souviendra.
